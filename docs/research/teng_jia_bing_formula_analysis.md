# 《三国志·战略版》藤甲兵战法机制与统率加成关系实证研究

## 摘要

在《三国志·战略版》玩家社区与常规游戏攻略中，藤甲兵的兵刃减伤效果常被概括为“满级 24%，受统率影响，实战通常在 35%~40% 左右”。由于游戏内战法说明未公布底层数学公式，且战内统率受适性、协力、特性等多重动态影响，导致该机制长期缺乏精确量化。

本研究基于真实对战原始 JSON 战报数据库（覆盖于吉、满宠、曹操、诸葛亮、马岱等武将，战内统率区间跨度 `176.83 ~ 532.43`），全量提取准备回合藤甲兵实际生效数据，通过一元线性回归与严密数学逆推，证实了其底层加成数学模型，拟合优度达到 **$R^2 = 1.000000$**。

---

## 一、核心结论与数学公式

### 1. 最终确立的精确公式

满级（10级）藤甲兵在准备回合锁定的兵刃伤害降低比例为：

$$\text{减伤率}(\%) = 24\% \times \left( 1 + \frac{\text{战内实时统率} - 100}{350} \right)$$

展开形式为：

$$\text{减伤率}(\%) = 24\% + (\text{战内实时统率} - 100) \times \frac{24\%}{350}$$

$$= 17.142857\% + \text{战内实时统率} \times 0.0685714\%$$

### 2. 底层架构设计规律解析

该公式揭示了游戏策划对属性增益模块的标准架构逻辑：
* **基准锚点（100 统率）**：当武将的战内统率恰好为基准线 100 时，属性增益项为 0，减伤率等于战法票面基础值 **24.00%**；
* **翻倍常数（350 统率增量）**：分母常数为标准常数 **350**。即**统率相对基准值每提高 350 点（战内统率达到 450 时），战法减伤增益翻倍（+100% 基础值），达到 48.00%**；
* **单位收益斜率**：
  $$\frac{24\%}{350} \approx 0.0685714\% / \text{点统率}$$
  即：**每增加 100 点统率，精确提升约 6.857% 兵刃减伤**。

## 三、关键结算时序与机制细节

1. **时序优先级快照**：
   * 战法准备回合执行顺序：`被动战法 (1)` $\to$ `阵法 (2)` $\to$ **`兵种战法 (3)`** $\to$ `指挥战法 (4)`；
   * 藤甲兵作为兵种战法在第 3 优先级生效并**即时快照**当时的统率值。
   * 因此，来自指挥战法（如抚辑军民、暂避其锋、守而必固）在后续施加的统率增减**无法溯及藤甲兵**；
2. **战内统率影响构成**：
   * 影响藤甲兵减伤计算的统率包含：面板基础值 + 加点 + 红度 + 装备 + 兵种适性修正（S级 120%、A级 100%、B级 85%）+ 阵营协力（10%）+ 兵种营地加成（盾兵营+20统率）+ 兵书特性。
3. **灼烧负面效应**：
   * 携带藤甲兵的武将处于灼烧状态时，每回合额外损失兵力（伤害率 300%，兀突骨统领降为 250%）；该额外损兵为真实伤害机制，不被藤甲兵的兵刃减伤抵免。
